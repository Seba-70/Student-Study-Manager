# Student Study Manager

A simple Python-based application designed to help students organize their courses and manage their study tasks.

## Project Overview

Student Study Manager is a command-line application that allows students to add courses, create study tasks, track task progress, and manage their academic workload.

This project was developed to practice Python programming concepts through a practical application.

## Features

- Add Course: Add new courses to your course list.
- View Courses: Display all registered courses.
- Add Task: Create study tasks and assign them to specific courses.
- View Tasks: Display all tasks with their associated courses and statuses.
- Update Task Status: Change task status between To Do, In Progress, and Completed.
- Input Validation: Handle invalid inputs and prevent duplicate courses.

## How to Run

1. Make sure Python is installed on your computer.
2. Clone or download this repository.
3. Open the project folder in Visual Studio Code.
4. Open the terminal.
5. Run the following command:

python main.py
